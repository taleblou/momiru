# Code of Conduct

Contributors and maintainers should treat each other with respect regardless of experience, identity or background. Technical criticism should focus on evidence, implementation and behavior, not individuals. Harassment, insults, discriminatory abuse, threats and disclosure of private information are not acceptable.

Maintainers may moderate discussions, edit or close abusive comments, and restrict participation to keep collaboration constructive. Report conduct concerns privately to repository maintainers through the available GitHub reporting/contact channels. Do not publish personal or confidential information in issue threads.
