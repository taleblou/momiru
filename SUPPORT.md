# Support

For API questions, first read [README.md](README.md), [docs/getting-started.md](docs/getting-started.md), the appropriate module guide, [API reference](docs/reference/README.md), [troubleshooting](docs/troubleshooting.md), and corresponding examples. For a reproducible bug or feature request, use the GitHub issue templates at `https://github.com/taleblou/momiru/issues`. Provide the selected module (`tensor` or `tensor_light`), pinned Rust compiler version, target triple, minimal reproduction, input shapes/dtypes, and expected/actual behavior. Do not attach sensitive input datasets or secret tokens. Security reports belong in private channels described in [SECURITY.md](SECURITY.md).
